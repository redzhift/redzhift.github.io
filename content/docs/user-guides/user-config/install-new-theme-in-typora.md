# Install new theme in Typora

{{% steps %}}
__Typora__ is a minimalist text editor that renders markdown and code in real-time. The software comes with several default themes that can be applied through the **Themes** option menu.

First, find which custom theme you'd like to install from the [Typora themes page](https://theme.typora.io/).

1. **Download** the theme.

2. **Open Typora** and navigate to the **File > Preferences** menu. The keyboard shortcut is `Ctrl + comma`

   ![The Appearance tab in the Preferences options menu][typora-1]

3. Go to the __Appearance__ tab and **Open Theme Folder**. 

4. **Extract the files** from the downloaded `.zip` into the themes folder. You should have:

   - A folder containing the theme's fonts (`.tff`, `.otf`,`.woff` files)
   - A `.css` file with the theme's styling
     

   ![The Typora themes folder containing theme folders and .css files][typora-2]

5. **Restart** **Typora** to refresh the available themes.

6. **Apply** the new theme through the **Themes** menu, or from **File > Preferences > Appearance** options.

   ![Applying a newly available Typora theme after refreshing the application through the Themes menu.][typora-3] ![Applying a newly available Typora theme through the Preferences menu and Appearance tab options.][typora-4]

{{% /steps %}}
