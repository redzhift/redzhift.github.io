    Downgrade with eos-shifttime

    Downgrade with eos-shifttime#

    Using eos-shifttime does not revert AUR packages. The downgrade only applies to official Arch packages from the archive repositories.

    The eos-shifttime application can revert system packages to their state at a specified date.

    1. Open a terminal window and run eos-shifttime with root permissions.

    2. Select the date to revert to on the GUI window, then click Revert.

    3. Reboot to apply the changes.

    Set up a downgrade shortcut

    To set up eos-shifttime to conveniently run from the Welcome app, follow the steps in the Adding own commands guide.

    The full eos-shifttime script can also be viewed at /usr/bin/eos-shifttime. It was formerly known as the “Easy Downgrade by Date” tool.
